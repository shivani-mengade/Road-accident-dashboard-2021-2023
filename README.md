# Road Accident Dashboard

This repository contains an **Road-accident-dashboard-2021-2023** that visualizes road accident data from 2021–2023. It includes key metrics such as total casualties, severity breakdowns, trends over time, and breakdowns by vehicle type, location, road surface and more.

---

## 📊 Overview

This Excel dashboard provides a clear visual summary of road accident statistics from **2021–2023**, helping users understand patterns in:

- Fatal, serious, and slight casualties
- Monthly trends and comparisons
- Casualties by vehicle type, road type, and surface
- Location (urban vs rural)
- Time of day (daylight vs dark)

This tool is ideal for traffic analysts, safety researchers, policymakers, or anyone looking to explore road safety data visually.

---

## 📁 Features

### 🧮 Summary Metrics
- Total casualties
- Fatalities and severity breakdown
- Casualties by vehicle type

### 📈 Trend Analysis
- Monthly casualty trends (Year-over-Year)
- Easy comparison between years (2021, 2022, 2023)

### 📍 Breakdown Visuals
- Casualties by:
  - **Road type**
  - **Road surface conditions**
  - **Location (urban vs rural)**
  - **Day/Night conditions**
  
### 🎛️ Interactive Filtering
- Use built-in slicers to filter by year or location type
- Explore specific patterns with one click

---

## 📊 Dashboard Layout

| Section | Insight |
|---------|---------|
| **Top Summary** | Key casualty counts and percentages |
| **Trend Chart** | Monthly comparison between years |
| **Category Charts** | Breakdown by vehicle, road type, surface |
| **Pie Charts** | Distribution by location & day/night |
| **Filter Panel** | Interactive filters for analysis |
